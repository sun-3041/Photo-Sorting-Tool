# PickFrame 图片筛选器

一个本地运行的 Windows 图片筛选工具。图片只在电脑本地读取和导出，不会上传。

## 启动

本机已安装 Python 和 Pillow 时，直接双击 `start.bat`。

如果提示缺少依赖，先双击 `install_dependencies.bat`，安装完成后再运行 `start.bat`。

## 使用

1. 点击“导入图片”选择多个文件，或点击“导入文件夹”递归导入文件夹及子文件夹内的图片。
2. 使用键盘 `←` / `→` 浏览上一张或下一张图片。
3. 使用键盘 `↑` 标记当前图片，`↓` 取消标记；空格可切换标记状态。
4. 在图片上滚动鼠标滚轮缩放，按住鼠标左键拖动；双击图片可恢复适合窗口。
5. 点击“全屏查看”或按 `F11` 进入全屏；全屏下筛选操作不变，按 `Esc` 或 `F11` 退出。
6. 选择导出格式和质量，点击“导出已选”进入复核；用方向键浏览并可用 `↓` 移除不满意图片，再点击“确认导出”选择目标文件夹。

其他快捷键：`Home` 第一张，`End` 最后一张，`Esc` 在普通窗口中恢复适合窗口，`Ctrl+O` 导入图片，`Ctrl+Shift+O` 导入文件夹，`Ctrl+E` 导出。

## 格式支持

- 默认支持：JPEG/JFIF、PNG、WebP、AVIF、TIFF、BMP、GIF、ICO、PSD、PNM/PPM/PBM/PGM、PCX、QOI 等 Pillow 可解码格式。
- HEIC/HEIF 与相机 RAW（DNG、CR2/CR3、NEF、ARW、RAF、RW2 等）需要额外组件。双击 `install_optional_formats.bat` 安装。
- 动图导入后显示首帧。
- 可导出为原格式、JPEG、PNG、WebP、TIFF 或 BMP。JPEG/BMP 不支持透明通道，透明区域会使用白色背景。

导出目录不能与任一原图所在目录相同。程序只会复制或转换到单独目录，绝不会移动、覆盖或修改原图。

导出时不会覆盖已有文件；同名文件会自动追加 `_2`、`_3` 等编号。

## 隐私

程序没有网络上传逻辑。只有执行依赖安装脚本时会连接 Python 软件包源。
